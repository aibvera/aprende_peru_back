# Aprende perú

Backend de aplicación web de compra de cursos asíncronos online para presentación final del curso de fullstack.

Incluye API REST con JWT, endpoints documentados, conexión con MySQL. También se ha incluido CORS, helmet, pruebas unitarias y de integración.

**Desarrollado por Alejandro Bueno**

Noviembre 2025

---

### Instalación

- Descargar el repositorio y abrirlo con VSCode u otro IDE.
- Crear y actualizar el archivo `.env` en la raiz del proyecto con las variables de entorno que representan las credenciales y URLs de acceso a la base de datos. Las variables usadas en el desarrollo están en el `.txt` subido a Paideia.
- Instalar modulos necesarios (`npm install`).

---

### Uso de la app

- Levantar el servidor con `npm start` o `npm run dev` (daemon).

---

### Notas

- La documentación del proyecto está en `api-doc` (ej.: `localhost:3000/api-doc`).
